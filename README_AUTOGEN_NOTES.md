## 테스트홀릭 자동 생성 운영 메모

- 자동/수동 생성 시 `VIRAL_TEST_GUIDELINES.md`를 최우선 기준으로 삼는다.
- 새로운 테스트를 만들 때는 제목보다 먼저 **결과명 4개**를 잡고 시작하는 것이 좋다.
- 기존처럼 무난한 심리상담형 문구보다, SNS에서 공유하고 싶은 캐릭터형 표현을 우선한다.
- 문항은 실제 장면형 위주로 작성한다.
- 선택지 순서 고정 금지.
- 2026-10-28 현수님 요청: 앞으로 신규 테스트는 상황에 맞는 썸네일과 공유 이미지도 함께 제작한다. 랜딩의 `thumbnail`/`image`, 결과별 `result_image`/`image`를 연결하고 홈·목록·실제 공유용 메타데이터까지 확인한다. 크론 재개 요청은 아니며 중단 상태를 유지한다.
